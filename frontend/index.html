    3 · API / script

    Same backend the UI uses. Good for bulk imports.

    # single file
curl -F "files=@shot.png" \
     -F "source=https://github.com/…" \
     localhost:8000/api/upload

# text note
curl -X POST localhost:8000/api/memories \
  -H 'Content-Type: application/json' \
  -d '{"title":"FAISS notes",
       "content":"vector index for dense retrieval"}'

# server-side path ingest
curl -X POST localhost:8000/api/ingest \
  -H 'Content-Type: application/json' \
  -d '{"path":"/abs/path/to/file.pdf"}'
